## 🚀 为什么选择 ACE-Step UI？

**厌倦了每月为 Suno 或 Udio 支付 10 美元以上？** ACE-Step 1.5 是**开源的 Suno 杀手**，可在你自己的 GPU 上本地运行 - 而 ACE-Step UI 为你提供了一个**美观、专业的界面**来充分发挥其强大功能。

| 特性 | Suno/Udio | ACE-Step UI |
|------|-----------|-------------|
| **费用** | $10-50/月 | **永久免费** |
| **隐私** | 云端处理 | **100% 本地** |
| **所有权** | 受许可限制 | **完全归你所有** |
| **自定义** | 有限 | **完全控制** |
| **队列限制** | 受限 | **无限制** |
| **商业使用** | 需付费升级 | **无任何限制** |

### ACE-Step 1.5 的特别之处

- **顶尖音质** 可媲美商业服务
- **完整歌曲生成** 最长 4 分钟以上，带人声
- **本地运行** - 安装后无需联网
- **开源** - 可查看、修改、改进
- **活跃开发** - 持续改进中

### 🪟 Windows - 一键启动（最简单！）
```batch
cd ace-step-ui
start-all.bat
```
**就这样！** 一条命令启动所有服务：API + 后端 + 前端。

> **注意：** 默认在 `..\ACE-Step-1.5` 目录查找 ACE-Step。
> 如果你的安装路径不同，请先设置 `ACESTEP_PATH`：
> ```batch
> set ACESTEP_PATH=C:\path\to\ACE-Step-1.5
> start-all.bat
> ```

### 🪟 Windows - 手动启动
```batch
REM 1. 启动 ACE-Step Gradio（带 API 端点）
cd C:\ACE-Step-1.5
python_embeded\python -m acestep --port 8001 --enable-api --backend pt --server-name 127.0.0.1

REM 2. 启动 ACE-Step UI（在另一个终端中）
cd ace-step-ui
start.bat
```

### Linux / macOS - 一键启动（最简单！）
```bash
cd ace-step-ui
./start-all.sh
```
**就这样！** 一条命令启动所有服务：Gradio + 后端 + 前端。

> **注意：** 默认在 `../ACE-Step-1.5` 目录查找 ACE-Step。
> 如果你的安装路径不同，请先设置 `ACESTEP_PATH`：
> ```bash
> export ACESTEP_PATH=/path/to/ACE-Step-1.5
> ./start-all.sh
> ```
> **停止服务：** `./stop-all.sh`

### Linux / macOS - 手动启动
```bash
# 1. 启动 ACE-Step Gradio 及 API（在 ACE-Step-1.5 目录中）
cd /path/to/ACE-Step-1.5
uv run acestep --port 8001 --enable-api --backend pt --server-name 127.0.0.1

# 2. 启动 ACE-Step UI（在另一个终端中）
cd ace-step-ui
./start.sh
```

### Windows（标准安装）
```batch
REM 1. 启动 ACE-Step Gradio 及 API（在 ACE-Step-1.5 目录中）
cd C:\path\to\ACE-Step-1.5
uv run acestep --port 8001 --enable-api --backend pt --server-name 127.0.0.1
```

## 📦 安装

### 1. 安装 ACE-Step（AI 引擎）

#### 🪟 Windows 便携包（Windows 用户推荐）

**Windows 上最简单的安装方式！** 此包已预配置所有内容：

1. **下载** [ACE-Step-1.5.7z](https://files.acemusic.ai/acemusic/win/ACE-Step-1.5.7z)（约 5GB）
2. **解压** 到 `C:\ACE-Step-1.5`（或你喜欢的位置）
3. **完成！** 包内已包含 `python_embeded` 及所有依赖

✅ **支持 4GB 显存 GPU** - 无需安装 LLM
✅ **包含 CUDA 12.8**
✅ **零配置麻烦**

> **注意：** 在显存小于 12GB 的 GPU 上，思考模式（LLM 功能）会自动禁用。如果你有 12GB+ 显存，可以手动启用。

#### 标准安装（所有平台）

```bash
# 克隆 ACE-Step 1.5 - 开源 Suno 替代方案
git clone https://github.com/ace-step/ACE-Step-1.5
cd ACE-Step-1.5

# 创建虚拟环境并安装
uv venv
uv pip install -e .

# 模型会在首次运行时自动下载（约 5GB）
cd ..
```

### 2. 安装 ACE-Step UI（本仓库）

#### Linux / macOS
```bash
# 克隆 UI
git clone https://github.com/fspecii/ace-step-ui
cd ace-step-ui

# 运行安装脚本（安装所有依赖）
./setup.sh
```

#### Windows
```batch
REM 克隆 UI
git clone https://github.com/fspecii/ace-step-ui
cd ace-step-ui

REM 运行安装脚本（安装所有依赖）
setup.bat
```

#### 手动安装（所有平台）

```bash
# 安装前端依赖
npm install

# 安装服务器依赖
cd server
npm install
cd ..

# 复制环境配置文件
# Linux/macOS:
cp server/.env.example server/.env
# Windows:
copy server\.env.example server\.env
```

## ⚙️ 配置

编辑 `server/.env`：

```env
# 服务器

# ACE-Step Gradio URL（必须与启动 ACE-Step 时使用的 --port 匹配）

# 可选：Pexels API 用于视频背景
PEXELS_API_KEY=your_key_here
```

## 🎼 生成模式

### 简单模式
只需描述你想要的内容，ACE-Step 会处理其余部分。

> "一首关于夏日冒险的欢快流行歌曲，带有朗朗上口的副歌"

### 自定义模式
完全控制每个参数：

| 参数 | 说明 |
|------|------|
| **歌词** | 带有 `[Verse]`、`[Chorus]` 标签的完整歌词 |
| **风格** | 流派、情绪、乐器、节奏 |
| **时长** | 30-240 秒 |
| **BPM** | 60-200 每分钟节拍数 |
| **调性** | 音乐调性（C 大调、A 小调等） |

### AI 增强与思考模式

| 模式 | 作用 | 速度影响 |
|------|------|---------|
| **AI 增强关闭** | 直接将你的风格标签发送给模型 | 最快 |
| **AI 增强开启** | LLM 将你的标签丰富为详细描述，并生成合适的 BPM、调性、拍号 | +10-20秒 |
| **思考模式** | 完整的 LLM 推理，生成音频编码 | 最慢，质量最佳 |

> **提示：** 如果你的流派标签（如 "流行、摇滚"）生成的结果像抒情歌曲，请开启 **AI 增强** 以获得更准确的流派匹配。无需额外显存 — LLM 使用 PT 后端在 CPU 上运行。

### 批量大小与批量生成

| 设置 | 说明 |
|------|------|
| **批量大小** | 每个任务生成的变体数量（1-4）。默认为 **1** 以兼容更多 GPU。更高的值会生成更多变体但使用更多显存。**8GB 显存用户应保持为 1。** |
| **批量生成** | 排队多个独立生成任务（1-10）。每个任务按顺序运行，因此对任何 GPU 都安全。 |
| **LM 后端** | 在 **PT**（约 1.6 GB 显存）和 **VLLM**（约 9.2 GB 显存）之间选择。PT 是默认值，适用于大多数 GPU。 |

> **提示：** 批量大小和批量数量都会保存在浏览器中 — 设置一次，以后会话会记住。

## 🐛 故障排除

| 问题 | 解决方案 |
|------|---------|
| **无法连接 ACE-Step** | 确保 Gradio 服务器已使用 `--enable-api` 标志运行（参见使用部分） |
| **CUDA 内存不足** | 使用 `--backend pt`（默认），将批量大小设为 **1**，减少时长，或禁用思考模式 |
| **4GB 显存 GPU - 内存不足** | 使用 **PT** 后端（默认），批量大小 **1**，并保持**思考模式关闭**。LLM 功能需要 12GB+ 显存 |
| **流派总是听起来像抒情歌曲** | 在风格部分启用 **AI 增强** 开关 — 它会用合适的元数据丰富你的标签 |
| **AttributeError: 'NoneType'** | 更新到最新的 ACE-Step-1.5（修复已合并到 PR #109） |
| **歌曲显示 0:00 时长** | 安装 FFmpeg：`sudo apt install ffmpeg`（Linux）或从 [ffmpeg.org](https://ffmpeg.org) 下载（Windows） |
| **局域网访问不工作** | 检查防火墙是否允许端口 3000 和 3001 |
